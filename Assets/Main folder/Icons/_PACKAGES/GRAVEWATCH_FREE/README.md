# GRAVEWATCH FREE — Dark Fantasy HUD

The free cut of GRAVEWATCH. Enough to build a complete HUD and ship a game
with it.

## What is in here

- **17 HUD pieces in iron** — the whole set in one finish: meters,
  portrait frames, buff cells, action slots, minimap ring, compass strip,
  cast bar, target reticle, quest panel, brackets.
- **2 pieces in bronze** — so you can see what a second finish looks like.
- **24 fill masks and HUD marks** — all of them. The meters do not work
  without the masks, and a free pack that does not work is not a sample.
- **15 sounds** — the whole HUD family, one impact against each of the four
  materials, and the health pair.
- 1 seamless stone tile and the full palette.

## The thing to understand in one minute

Meters ship as **a frame plus a separate fill mask**, never as a coloured bar.
Tint `masks/trilho_barra.png` red for health, blue for mana, gold for stamina —
the same frame serves all of them. The frame openings are genuinely
transparent, so whatever you put behind shows through.

## About the sounds

Play the four impacts back to back: shield, mail, flesh, stone. There is no
"sword sound" — what the ear identifies is the pair of materials, and the same
swing against those four has nothing in common. That is the idea the full kit
is built on.
